<Update label="2026-10-28" tags={["发布"]} description="v0.6.5-beta.1">

- 整合上游 Moe 的运行时与构建流程，保留本项目原有 ACG 首页和 MD3 界面；Mihomo 更新为 Alpha 5b79f3c3。
- 更新检测改为直接读取本仓库 GitHub Releases，支持预发布版本、前台每 6 小时自动检查、下载进度、取消与重试，并校验安装包身份、版本及签名。
- 更新封面按原图比例显示，支持点击预览、缩放和长按保存。
- 备份扩展为包含设置、配置源文件、覆写及绑定、壁纸、统计、日志、Geo 和 Sub-Store 数据的 ZIP，兼容旧版 JSON 设置备份。
- 内置匹配的 Sub-Store 引擎，修复版本不匹配引起的原生崩溃、前后端连接与离开页面后定时关闭失效。
- 节点卡片改为自然高度瀑布流并保持一致间距；修复批量测速串行、并发设置不生效和测速时列表卡顿。
- 修复配置 JSON、重命名、覆写导入及 emoji 引起的闪退，自定义分流无法返回，以及连接详情滚动崩溃（[#3](https://github.com/Yizuka17/YumeBox-MaterialDesign/issues/3)）。
- 超级岛与代理通知打开应用首页，移除旧节点弹层；调整设置分组，地区标识恢复大写。
- 恢复控制中心和通知栏的原猫咪图标，快捷开关名称统一为 YumeBox MD3；该修复合并在本条 Beta 1 Release，安装版本号为 6505。

[Release](https://github.com/Yizuka17/YumeBox-MaterialDesign/releases/tag/v0.6.5-beta.1) · [版本间提交](https://github.com/Yizuka17/YumeBox-MaterialDesign/compare/v0.5.5-alpha...v0.6.5-beta.1)

</Update>

<Update label="2026-06-01" tags={["发布"]} description="v0.5.4">

- 版本号更新至 `0.5.4`，并让 native bridge 构建直接读取项目 Git 版本信息，减少手工维护版本号的偏差
- 新增服务通知语言运行时和今日流量读取能力，优化 Tun / Root Tun 服务通知的状态文案与本地化展示
- 强化 Sub-Store 下载体验，补充下载进度、状态提示、取消/重试流程和健康检查相关设置
- Meta 特性页继续完善 GeoX 文件更新流程，增强校验、进度、错误提示与设置备份/恢复链路
- 修复运行时代理选择同步问题，减少进入代理页或服务重载后节点选择状态不一致的情况
- 继续打磨页面动效、按钮按压反馈、底部栏滚动隐藏、页面滚动位置恢复和危险操作确认样式
- 优化代理页、日志页、流量统计、ACG 首页、配置覆写列表与编辑器相关交互细节
- 调整应用启动、主题与偏好设置中的若干文案和布局细节，补充中英文与繁体中文翻译
- 修复生成的 Geo 压缩资源重复打包导致 APK 体积增大的问题。

<Update label="2025-11-27 ~ 2026-4-9" tags={["归档", "历史"]} description="MD3 化前历史摘要">

  MD3 化之前的逐版本流水账已合并为摘要，避免当前更新页过长。完整标签、下载资产和原始发行记录仍可在 GitHub Releases 查看。

- 从早期测试版逐步独立出基于 mihomo 内核的 Android 客户端，完成包名变更、初始化流程、多语言、订阅导入、二维码/剪贴板导入、外部控制和 Web 面板等基础能力
- 持续增强代理和节点体验，包括代理启动优化、节点选择与排序、延迟测试、代理组图标/旗帜显示、通知栏快捷切换、Root Tun、连接页面与流量统计

- 移除部分旧实验能力和第三方服务，包括液态玻璃、Sentry 跟踪器和 EMAS 推送更新，并持续优化稳定性、打包体积和后台资源释放
