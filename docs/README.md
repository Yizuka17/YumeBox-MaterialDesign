## Download

Supports **Android 8.0 (API 26) or later**, **arm64-v8a**.

Download `YumeBoxMD3-builtin.apk` from [GitHub Releases](https://github.com/Yizuka17/YumeBox-MaterialDesign/releases). To receive Alpha/Beta updates in the app, enable **接收预发布版本** (receive prerelease versions) under **Settings → About**.

## Features

- **MD3 and ACG home**: Material You colors, light/dark themes, custom wallpapers and Daily Quote.
- **Profiles and overrides**: profile imports and updates, YAML/JSON editing, override bindings and custom routing.
- **Nodes and proxies**: Rule / Global / Direct modes, single-node and batch latency checks, sorting and masonry node cards.
- **Sub-Store and Geo**: bundled matching Sub-Store engine, subscription management, Geo updates and local imports.
- **Backups and statistics**: ZIP backup/restore for settings, profiles, overrides and other app data; traffic statistics and logs.
- **HyperOS integration**: Super Island and service notifications open the home page; Quick Settings toggles the proxy.
