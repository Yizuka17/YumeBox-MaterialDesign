## 小窗与横竖屏布局回归（2026-10-28）

旧包在小米真实自由窗口复现 IP 行和配置胶囊重叠；在类原生缩小窗口时，一言也会覆盖底部控制区。原因是首页信息、胶囊和一言分别依赖固定比例或绝对偏移。现将它们放进同一条可滚动内容流，按真实内容高度排列，为底部操作预留实际测量高度；窄窗流量标签上下排列并自动换行，过长节点/IP 用省略号处理，侧栏在矮窗口可滚动。

旧包横屏回竖屏后壁纸异常放大也已实机复现。首页把历次窗口最大宽、高分别缓存，再以 EXACTLY 提前裁剪位图，丢失后续构图所需像素。现保留原图比例，根据当前窗口解码，由显示层裁切。
