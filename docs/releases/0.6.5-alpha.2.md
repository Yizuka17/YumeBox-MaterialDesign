本次为 Alpha 测试版，用于持续试用和 GitHub Releases 更新流程验证。

- 修复覆写配置、配置 JSON 编辑器闪退，以及导入、重命名遇到中文和 emoji 时的异常。
- 修复自定义分流页面无法返回；未修改时直接返回，保存失败时提供重试或放弃修改。
- 超级岛和代理通知点击后打开应用首页，移除旧节点弹层。
- 应用设置按「首页、主题、界面、服务、行为、隐私」排列；网络选项移至网络设置。
- 恢复首页出口 IP 地区标识的大写显示，如 JP、HK。
- 保留原 ACG 首页与 MD3 界面，节点和代理组使用等间距瀑布流。
- 整合上游运行架构、更新 mihomo，直接从 GitHub Releases 检查更新；更新弹窗加载本页封面。

APK：`YumeBoxMD3-builtin.apk`，仅 arm64-v8a，内置 Geo 数据，使用原签名，可覆盖安装。

测试此 Alpha 的更新提示时，请在「关于」中开启「包含预发布版本」，再手动检查更新。
Root TUN/eBPF、实际重启自启和生物识别尚未完成实机验收。
