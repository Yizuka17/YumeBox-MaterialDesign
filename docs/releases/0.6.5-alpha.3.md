Alpha 测试版，保留原 ACG 首页与 MD3 设计，用于试用及验证 GitHub Releases 更新流程。

- 整合上游 Moe，Mihomo 更新至 Alpha `5b79f3c3`。
- 修复配置 JSON、重命名、覆写导入与 emoji 引起的闪退；修复自定义分流无法返回。
- 修复批量测速被串行执行、并发设置不生效和测速时列表卡顿；保留原单节点测速入口。
- 备份包含设置、配置源文件、覆写、绑定、壁纸、统计、日志、Geo 与 Sub-Store 数据，兼容旧 JSON 设置备份。
- 封面按原图比例显示，支持点击预览、缩放及长按保存。
- 内置匹配的 Sub-Store 引擎，修复启动、前后端连接与离开页面后定时关闭失效。
- 超级岛和通知打开应用首页；设置分组重新排列，“ACG 实验首页”改为“ACG 首页”，地区标识恢复大写。

`YumeBoxMD3-builtin.apk`：arm64-v8a，内置 Geo 与 Sub-Store 引擎，原签名覆盖安装。

验证更新提示时，请在“关于”开启“接收预发布版本”，再检查更新。
详细实测范围见 [验证记录](https://github.com/Yizuka17/YumeBox-MaterialDesign/blob/codex/upstream-release-core/docs/DEVICE_VALIDATION.md)。Root 功能按维护者要求未测。
