![Release 封面](https://raw.githubusercontent.com/Yizuka17/YumeBox-MaterialDesign/v0.6.5-beta.2/docs/releases/0.6.5-beta.2-banner.jpg)

- 新增“平板模式优化”：ACG 首页显示横排连接时长和带名称的侧栏入口，支持独立平板壁纸与裁切。
- 新增每日 ACG 壁纸，竖屏、平板可分别设置 API 和自定义图片池，支持每日更换、手动刷新与缓存兜底，相关图片和设置纳入备份。
- 首页侧栏新增同款黑白应用图标的壁纸刷新入口，开启每日壁纸轮播后显示，刷新过程不弹提示。
- 新增 API 缓存池查看；缓存与自定义图片均可大图预览、缩放，长按保存原图或移除图片，操作弹窗支持点击外侧关闭。
- 加大平板图片池卡片，“添加图片”随文字高度调整；壁纸设置提供独立的一键恢复默认，精简说明和操作箭头。
- 超级岛点击后恢复退出前的页面；电池优化无限制采用上游系统授权方案。
- 修复“跟随系统”的明暗切换及系统栏外观同步。
- 改善小窗和极矮窗口布局，避免节点、IP、配置胶囊与一言重叠，代理控制区可随页面滚动。
- 修复横屏切回竖屏后壁纸异常放大的问题，按当前窗口保持构图。
- 修复更新封面的保存菜单不能点击外侧关闭，以及调整字体或窗口尺寸后意外返回首页的问题。

`YumeBoxMD3-builtin.apk`：arm64-v8a，内置 Geo 数据库和 Sub-Store 引擎。

检查此测试版时，请在“关于”开启“接收预发布版本”。
