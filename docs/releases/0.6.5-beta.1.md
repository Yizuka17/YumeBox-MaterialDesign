Beta 测试版，保留原 ACG 首页与 MD3 设计。本次从 Alpha 调整为 Beta，版本号提升至 6503，便于从已安装的 Alpha 检测并覆盖更新，功能代码与 Alpha 3 一致。

- 整合上游 Moe，Mihomo 更新至 Alpha `5b79f3c3`。
- 修复配置 JSON、重命名、覆写导入与 emoji 引起的闪退；修复自定义分流无法返回。
- 修复批量测速串行执行、并发设置不生效和测速时列表卡顿；保留原单节点测速入口。
- 备份包含设置、配置源文件、覆写、绑定、壁纸、统计、日志、Geo 与 Sub-Store 数据，兼容旧 JSON 设置备份。
- 封面按原图比例显示，支持点击预览、缩放及长按保存。
- 内置匹配的 Sub-Store 引擎，修复启动、前后端连接与离开页面后定时关闭失效。
- 超级岛和通知打开应用首页；设置分组重新排列，“ACG 实验首页”改为“ACG 首页”，地区标识恢复大写。

`YumeBoxMD3-builtin.apk`：arm64-v8a，内置 Geo 与 Sub-Store 引擎，原签名覆盖安装。

请在“关于”开启“接收预发布版本”，再检查更新。
此前 Alpha 3 的实测范围见 [验证记录](https://github.com/Yizuka17/YumeBox-MaterialDesign/blob/codex/upstream-release-core/docs/DEVICE_VALIDATION.md)。开机解锁、生物识别和实拍扫码按维护者要求暂缓，Root 功能不测。
