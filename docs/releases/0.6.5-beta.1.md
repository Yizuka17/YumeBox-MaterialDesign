保留原有 MD3 界面和 ACG 首页，以下为相较 `0.5.5-alpha` 的主要变化：

- 整合上游 Moe 的运行时与构建流程，Mihomo 内核升级至 Alpha `5b79f3c3`。
- 更新检测改为直接读取本仓库 GitHub Releases，支持正式版与预发布版本筛选；开启自动检查后，应用在前台每 6 小时检查一次，下载后校验安装包身份、版本及签名。
- 更新封面按原图比例显示，支持点击预览、缩放和长按保存原图。
- 节点卡片改为自适应高度的两列瀑布流，长短名称保持一致间距。
- 备份从设置扩展为 ZIP 备份，包含配置源文件、覆写及绑定、壁纸、统计、日志、Geo 和 Sub-Store 数据，兼容旧版 JSON 设置备份。
- 安装包内置匹配的 Sub-Store 原生引擎，无需另装引擎扩展包；首次使用仍需在应用内下载前后端资源。
- 新增 HyperOS 超级岛与 Shizuku 授权支持，显示订阅、节点和实时流量；超级岛和代理通知点击后进入应用首页。
- 应用设置按首页、主题、界面、服务、行为、隐私分组，网络与自定义 UA 集中到网络设置。

`YumeBoxMD3-builtin.apk`：arm64-v8a，内置 Geo 数据库和 Sub-Store 引擎。

检测此测试版时，请在“关于”开启“接收预发布版本”。
